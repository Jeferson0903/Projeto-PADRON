# Imagens de fundo (Padron)

O site está configurado para usar **12 imagens de fundo** enviadas por você.

## Onde cada imagem aparece

| Arquivo | Uso no site |
|---------|-------------|
| **padron-bg-01.png** | Hero (slide 1) – primeira tela da home |
| **padron-bg-02.png** | Hero (slide 2) |
| **padron-bg-03.png** | Hero (slide 3) |
| **padron-bg-04.png** | Seção Sobre (página Sobre) + faixa do marquee |
| **padron-bg-05.png** | Seção Serviços |
| **padron-bg-06.png** | Seção Depoimentos |
| **padron-bg-07.png** | Seção Projetos |
| **padron-bg-08.png** | Breadcrumb (título das páginas internas) |
| **padron-bg-09.png** | Seção Equipe |
| **padron-bg-10.png** a **padron-bg-12.png** | Reservadas para uso futuro |

## O que fazer

1. Coloque as 12 imagens que você enviou **nesta pasta** (`public/img/bg/`).
2. Renomeie assim:
   - 1ª imagem → `padron-bg-01.png`
   - 2ª imagem → `padron-bg-02.png`
   - … até a 12ª → `padron-bg-12.png`

Se as imagens forem `.jpg`, renomeie para `.jpg` (ex.: `padron-bg-01.jpg`) e avise para ajustarmos o código.
